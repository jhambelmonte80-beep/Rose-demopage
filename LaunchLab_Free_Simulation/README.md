# LaunchLab — Tool-by-Tool Free Simulation Course

This is a free, browser-based training environment for learning website launch and basic digital operations. It includes 9 modules and 27 lessons.

## What the simulations look like
Each lesson includes a tool-specific training replica with a realistic workspace layout, navigation menu, settings, tables, fields, status indicators, and guided actions. The lessons cover workflows commonly found in GitHub, Netlify, Cloudflare/DNS managers, Google Admin/Gmail, favicon generators, SEO tools, Search Console-style reports, crawlers, and PageSpeed/Lighthouse-style audits.

These are educational replicas, not exact copies of proprietary products. Product interfaces can change over time. The course focuses on the controls and workflow you need to understand.

## Completely free practice
- No account registration is required.
- No paid plans, domains, hosting, or subscriptions are required.
- No external websites are required to complete the lessons.
- All data is fictional and all changes stay in your browser.
- The simulations do not connect to or change real services.

## Files
- `index.html` — complete interactive course
- `course-data.json` — course outline and lesson data
- `assets/favicon.svg` — course icon

## Open locally
Open `index.html` in a browser. Progress is stored in browser local storage.

## Optional: publish the training site
You can upload the folder contents to a GitHub repository and enable GitHub Pages if you want to access the course online. This is optional and not needed to complete the course.
